## Required System Specifications

The recommended system requirements for this training environment are listed below:

- RAM: 4 GB – 16 GB
- Processor: Minimum 1 GHz Dual-Core (64-bit recommended)
- Storage: At least 2 GB of free disk space
- Operating System: Windows 10 or later recommended

---

## Recommended Downloads

Learners whose systems meet the recommended specifications can install PostgreSQL and pgAdmin 4 using the official EnterpriseDB installer:

### PostgreSQL & pgAdmin 4:
  https://www.enterprisedb.com/downloads/postgres-postgresql-downloads

---

## Legacy System Support (32-bit )

To support learners using older or low-spec systems, alternative lightweight and legacy-compatible tools are provided below.

Recommended for:

- Windows 7 systems
- 32-bit laptops
- Low-resource devices

### Downloads

- DBeaver (Legacy Version)
https://dbeaver.io/files/4.2.6/

- PostgreSQL 12
https://postgrespro.com/windows

- PostgreSQL JDBC Driver
https://jdbc.postgresql.org/download/

---

## Notes

- PostgreSQL 12 was selected for compatibility with older hardware and operating systems.
- DBeaver legacy versions provide better support for low-resource and 32-bit environments.
- Learners using modern systems are encouraged to use the latest stable PostgreSQL and pgAdmin releases where possible.
- Learners whose system is below 32 bits, are encouraged to use their mobile phone for the training.
